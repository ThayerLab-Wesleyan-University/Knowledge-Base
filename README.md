## Contributing

See the [PDF submission instructions](pdf/README.md) or [Markdown submission instructions](markdown/README.md). Submit only material that may be stored in this repository and sent to the configured LLM provider.

Automated ingestion is under development. Once implemented, it will archive original submissions, generate summaries and keywords, and update the graph and links above.

Development details and acceptance criteria are in the [implementation roadmap](ROADMAP.md).
